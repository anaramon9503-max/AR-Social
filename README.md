# AR Social & Web - Tarjeta Digital

Tarjeta digital lista para publicar en GitHub Pages.

## Archivos
- `index.html`
- `style.css`
- `script.js`
- `logo-ar-social-web.jpg`

## Cómo subirla a GitHub
1. Crea un repositorio nuevo.
2. Sube todos los archivos de esta carpeta a la raíz del repositorio.
3. En GitHub entra a **Settings > Pages**.
4. En **Build and deployment**, selecciona **Deploy from a branch**.
5. Elige la rama `main` y la carpeta `/root`.
6. Guarda y espera a que GitHub genere el enlace.

Los botones de WhatsApp, Facebook y ubicación ya están configurados.
