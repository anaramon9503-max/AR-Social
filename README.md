# AR Social & Web — Tarjeta Digital Pro

Versión mejorada para GitHub Pages.

## Mejoras
- Menús desplegables corregidos.
- Solo un menú queda abierto a la vez.
- El mismo menú puede cerrarse al volver a tocarlo.
- Animación suave y estable.
- Diseño más limpio y profesional.
- Optimizado para celular.
- Botones de WhatsApp, Facebook y ubicación configurados.

## Publicar en GitHub Pages
1. Descomprime el ZIP.
2. Sube `index.html`, `style.css`, `script.js` y `logo-ar-social-web.jpg` a tu repositorio.
3. Ve a **Settings > Pages**.
4. En **Build and deployment**, selecciona **Deploy from a branch**.
5. Elige `main` y `/root`.
6. Guarda.

Si ya tenías una versión anterior, reemplaza los archivos viejos por estos.
